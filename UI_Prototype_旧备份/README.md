# UI Prototype Pack

这套素材面向 Unity 3D 俯视角生存割草 Demo，统一采用暗黑奇幻风格：深色石质面板、蓝紫能量、金色边框、红色危险提示。

## 文件

- `ui_theme.svg`：主菜单、战斗 HUD、血条、经验条、技能槽、Boss 血条、升级卡、宝箱、按钮和常用图标的总图。
- `ui_components.svg`：暂停、设置、胜利、提示框、警告等系统组件。
- `ui_icons.svg`：生命、能量、时间、护盾和警告图标。
- `ui_meta_screens.svg`：角色选择、武器选择、装备、图鉴和局外成长界面组件。
- `ui_results_and_world.svg`：战斗结算、胜利/失败信息区域、小地图、提示条和加载条组件。

## Unity 使用建议

1. 将 SVG 导入 `Assets/UI_Prototype/` 或当前文件夹；如果项目未启用 Unity Vector Graphics，可先在图片编辑器中按 SVG 的分组区域导出 PNG。
2. `ui_theme.svg` 适合作为参考总图，切图后设置为 `Sprite (2D and UI)`。
3. 面板使用九宫格切片，边框宽度建议保留 24 到 36 像素；血条和经验条使用横向填充。
4. 推荐 Canvas Scaler 使用 `Scale With Screen Size`，参考分辨率 `1920x1080`。
5. 文本建议使用无衬线粗体，标题用暖金色，战斗提示用红色或蓝紫色。

## 已覆盖的界面

战斗 HUD、玩家血条、经验条、等级提示、技能栏、主动技能按钮、Boss 血条、升级三选一、宝箱奖励、暂停、胜利、失败、主菜单、设置、通用提示框、角色选择、武器选择、装备、图鉴、局外成长、结算、小地图、加载提示、货币/击杀/时间/等级/警告图标。
