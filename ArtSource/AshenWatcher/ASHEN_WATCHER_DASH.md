# Ashen Watcher dash

`AshenWatcher_Dash.blend` and `AshenWatcher_Dash.fbx` contain the in-place dash
clip for the existing player. The pose compresses, leans forward, extends and
returns to neutral over 19 frames at 30 fps. Root motion is not authored so the
game can move the player root itself.
