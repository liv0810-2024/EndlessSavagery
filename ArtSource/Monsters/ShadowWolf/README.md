# Shadow Wolf

Low-poly quadruped enemy with charcoal-violet fur, luminous mark, red eyes and
an alternating four-leg locomotion cycle.

- `ShadowWolf.blend`: editable source.
- `ShadowWolf_Walk.gif`: looping walk preview.
- `../../../../Assets/Characters/Monsters/ShadowWolf/ShadowWolf_Animated.fbx`: rigged FBX with `ShadowWolf_Walk`.
- GDD tuning reference: HP 70, damage 12, speed 3.5 m/s, XP 35.

The animation is in-place at 30 fps. Enable Loop Time on the imported walk clip
if needed.
