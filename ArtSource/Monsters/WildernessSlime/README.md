# Wilderness Slime

Low-poly green wilderness slime for the first wave. The model is built for the
existing Ashen Watcher visual language with a dark neutral review background,
simple emissive core and red eyes.

- `WildernessSlime.blend`: editable source.
- `WildernessSlime_Walk.gif`: looping walk/squash preview.
- `../../../../Assets/Characters/Monsters/WildernessSlime/WildernessSlime_Animated.fbx`: rigged FBX with `WildernessSlime_Walk`.
- GDD tuning reference: HP 30, damage 5, speed 2.2 m/s, XP 15.

The animation is in-place and authored at 30 fps. Enable Loop Time on the FBX
clip if the Unity importer does not enable it automatically.
