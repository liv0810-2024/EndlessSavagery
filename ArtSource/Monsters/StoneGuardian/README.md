# Stone Guardian

Heavy low-poly golem for the boss slot. It uses broad stone plates, violet core
cracks and a slow weighted stride.

- `StoneGuardian.blend`: editable source.
- `StoneGuardian_Walk.gif`: looping heavy-walk preview.
- `../../../../Assets/Characters/Monsters/StoneGuardian/StoneGuardian_Animated.fbx`: rigged FBX with `StoneGuardian_Walk`.
- GDD tuning reference: HP 300, damage 25, speed 1.8 m/s, XP 120.

The animation is in-place at 30 fps. Enable Loop Time on the imported walk clip
if needed.
