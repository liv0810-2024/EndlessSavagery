# 战斗与系统组件

这里的每个 SVG 都是独立文件，已经绕开 Tuanjie 对 Vector Sprite 不支持 Sprite Editor 切割的问题。

使用时直接把单个文件拖到 Unity UI Image、Button、SVG Image 或 Sprite Renderer，不要再打开原来的组合图执行 Slice。

已拆分的资源组：

- 战斗 HUD：`hud_frame`、`active_skill_button`、`bar_health`、`bar_xp`、`bar_boss`
- 常用信息：`coin_icon`、`kill_icon`、`level_badge`、`event_toast`、`minimap_frame`、`loading_bar`
- 局外界面：`character_card`、`weapon_slot`、`equipment_slot`、`codex_row`
- 设置控件：`toggle_on`、`toggle_off`
- 升级卡、面板、按钮和图标：使用同级 `Parts`、`Icons` 和 `Pages` 文件夹

原组合图仍保留在 `Assets/UI_Prototype/` 根目录作为整体视觉参考，不用于实际切割。
