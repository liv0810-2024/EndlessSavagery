## 使用原则

实际搭建 UI 时，优先使用 `01` 到 `06` 文件夹中的独立 SVG。不要再打开 Sprite Editor 切割 SVG；Tuanjie 的 Vector Sprite 不支持这个功能。

项目根目录下的 `UI_Prototype_旧备份` 是早期源文件备份，不会被 Unity 导入。实际开发只使用本目录，避免出现两个相似文件夹。
