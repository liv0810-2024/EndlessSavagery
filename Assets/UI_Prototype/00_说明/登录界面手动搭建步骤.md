# GameLogin 场景手动搭建登录界面

这份说明适合你当前的 `GameLogin` 场景。资源只负责外观，场景里的 Canvas、按钮、输入框和文字由你自己搭建，这样后续你可以自由修改。

## 一、素材位置

### 页面背景

`Assets/UI_Prototype/01_页面/page_login.svg`

这是整张登录页面背景，适合先快速查看整体效果。

### 独立素材

- `Assets/UI_Prototype/Parts/logo_endless_savagery.svg`：游戏标题装饰
- `Assets/UI_Prototype/Parts/input_field.svg`：输入框背景
- `Assets/UI_Prototype/Parts/button_primary.svg`：登录、确认等主要按钮
- `Assets/UI_Prototype/Parts/button_secondary.svg`：返回、取消等次要按钮
- `Assets/UI_Prototype/Parts/button_danger.svg`：退出、删除等危险操作按钮

## 二、先确认 SVG 可以显示

如果 SVG 可以拖到 UI Image 的 `Source Image`，直接使用即可。当前 `page_login.svg` 已改成兼容 Tuanjie 的纯色版本，避免渐变导致显示错乱。

如果拖不进去：

1. 打开 `Window > Package Manager`。
2. 安装 Unity Registry 里的 `Vector Graphics`。
3. 在 UI 物体上添加 `SVG Image` 组件。
4. 把 SVG 拖到 `Vector Graphic` 属性。

## 三、在当前场景创建登录界面

### 1. 创建登录根节点

1. 打开 `GameLogin` 场景。
2. 在 Hierarchy 找到已有的 `UICanvas`。
3. 右键 `UICanvas`，选择 `Create Empty`。
4. 命名为 `LoginUI`。
5. 给 `LoginUI` 添加 `RectTransform`，锚点设置为全屏：

   - Anchor Min：`0, 0`
   - Anchor Max：`1, 1`
   - Left / Right / Top / Bottom：`0`

### 2. 添加登录背景

1. 右键 `LoginUI`，选择 `UI > Image`。
2. 命名为 `LoginBackground`。
3. 拉伸到全屏。
4. 将 `page_login.svg` 拖到 `Source Image`，或者使用 `SVG Image` 组件。

如果你希望每个部件都能单独调整，可以不使用整张 `page_login.svg`，继续按下面的独立素材搭建。

## 四、添加标题

1. 右键 `LoginUI`，选择 `UI > Text` 或 `Text - TextMeshPro`。
2. 命名为 `GameTitle`。
3. 文本填写：`无尽狂野`。
4. 放在页面上方中央。
5. 可在标题物体上叠加 `logo_endless_savagery.svg` 作为装饰。

## 五、添加账号输入框

1. 右键 `LoginUI`，选择 `UI > Input Field`。
2. 命名为 `UsernameInput`。
3. 调整宽度约为 `400`，高度约为 `72`。
4. 将 `input_field.svg` 设置为背景 Image。
5. Placeholder 填写：`请输入账号`。

## 六、添加密码输入框

1. 复制 `UsernameInput`。
2. 命名为 `PasswordInput`。
3. Placeholder 改成：`请输入密码`。
4. 在 Input Field 的 `Content Type` 中选择：

   `Password`

这样输入内容会显示为星号。

## 七、添加登录按钮

1. 右键 `LoginUI`，选择 `UI > Button`。
2. 命名为 `LoginButton`。
3. 将 `button_primary.svg` 设置为按钮背景。
4. 子物体 Text 改成：`登录`。
5. 将按钮放在两个输入框下方。

## 八、添加游客登录和返回按钮

复制 `LoginButton` 两次：

- `GuestButton`：文字改为 `游客登录`
- `BackButton`：文字改为 `返回`

游客登录可以使用 `button_secondary.svg`，返回按钮可以使用 `button_danger.svg`。

## 九、推荐的 Hierarchy

```text
UICanvas
└── LoginUI
    ├── LoginBackground
    ├── GameTitle
    ├── UsernameInput
    ├── PasswordInput
    ├── LoginButton
    ├── GuestButton
    └── BackButton
```

## 十、注意事项

- 不要对 SVG 打开 Sprite Editor；Tuanjie 的 Vector Sprite 不支持切割。
- 每个独立 SVG 都可以单独拖入 UI Image 或 SVG Image。
- 输入框和按钮的文字使用 Unity Text 或 TextMeshPro，不要写进背景 SVG。
- 当前素材只负责 UI 外观，登录验证逻辑需要你之后在 Button 的 `On Click()` 中绑定自己的脚本。
- 之前的自动生成脚本已经移除，不会再自动修改你的场景。
