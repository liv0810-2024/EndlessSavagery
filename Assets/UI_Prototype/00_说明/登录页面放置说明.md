# 把登录页面放进当前 GameLogin 场景

项目中已经加入一键生成工具，脚本位置：

`Assets/Editor/BuildLoginUI.cs`

使用步骤：

1. 打开 `GameLogin` 场景。
2. 确认 Hierarchy 中有 `UICanvas`。
3. 等待 Unity 编译完成。
4. 点击顶部菜单：

   `Tools > Endless Savagery > Build Login UI In Current Scene`

5. 工具会在 `UICanvas` 下创建 `LoginUI_AutoGenerated`。
6. 工具会自动保存当前场景。

生成内容：

- 登录背景
- 游戏标题
- 账号输入框
- 密码输入框
- 登录按钮
- 游客登录按钮
- 返回按钮
- Demo 提示文字

如果重复执行，工具会先删除旧的 `LoginUI_AutoGenerated`，再重新生成一份，不会叠加多个登录界面。
